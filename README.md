## 💡 Overview

Most AI chatbots rely on surface-level instructions (*"You are a helpful assistant"*). 
This suite packages **exhaustive domain knowledge (7,000 to 22,000 characters of technical guardrails, zero-hallucination protocols, and industry frameworks)** into specialized prompt bots hosted on Poe's cloud infrastructure.

All agents run 24/7 without requiring local hardware, server costs, or API keys.
